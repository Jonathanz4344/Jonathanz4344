### ☁️ Self-Service Azure DBaaS (IBM)

**Impact:** Database provisioning cut from weeks in the DBA backlog to minutes  
**Stack:** `Azure` `Terraform` `Ansible/AWX` `GitHub Actions` `ServiceNow` `Oracle`

### 🏥 Custom EMR System
> Production EMR and practice-management system for a live optometry clinic (60–90 patient visits a week), covering structured charting, optical ordering, billing, inventory, and a login-free patient intake flow with e-signatures. Led its zero-downtime on-prem-to-AWS migration.

**Impact:** 85% less physician documentation time, 95% less intake paperwork, zero findings across HIPAA compliance reviews  
**Stack:** `FastAPI` `PostgreSQL` `React` `TypeScript` `AWS`
